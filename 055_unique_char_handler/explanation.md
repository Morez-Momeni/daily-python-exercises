# Problem 55: Count Duplicates and Extract Unique Characters

## Problem
Write a script that:
1. Counts the frequency of every character in a given string (ignoring spaces).
2. Filters out characters that appear more than once.
3. Joins the remaining unique characters (those appearing exactly once) into a single new string.

**Example:**
- Input: `"Hello mohammad it is teest for reemove duplicaate char"`
- Output: a string containing only the characters that appear **exactly once**.
