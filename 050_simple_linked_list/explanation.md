## Simple Linked List

A simple implementation of a **Singly Linked List** in Python.

In this example, each `Node` stores two things:

* `data` — the value stored in the node
* `next` — a reference to the next node

The nodes are connected together like this:

```text
100 → 200 → 300 → None
```

The `while` loop starts from the first node and follows the `next` references until it reaches `None`.

This example is mainly for understanding the basic concepts of **Node, data, next, and traversing a linked list**.
