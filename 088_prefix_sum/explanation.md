# Problem 88: Prefix Sum (Sum of First N Elements)

## Problem
Write a function `prefix_sum(arr, prefix_index)` that returns the sum of the **first `prefix_index` elements** of `arr`. If `prefix_index` is greater than the length of the list, return `False`.

**Example:**
- `prefix_sum([1, 2, 3, 4, 5, 6], 4)` → `10` (1 + 2 + 3 + 4)
