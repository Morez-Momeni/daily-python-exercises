## Problem
Create a simple login form using Tkinter. The form should:
- Display the current time.
- Have username and password fields.
- Validate credentials against a predefined list of users.
- Show a status message ("Logged In!" or "Failed!").
- Close the window after 2 seconds on successful login.

## My Solution (Current Version)

I built a Tkinter window with:
- A label showing the current time (updates every second).
- Labels and entry fields for username and password.
- A "Login" button that triggers validation.
- A status label that displays the result.
