# Problem 71: Sigilize - Magic Sigil Generator

## Problem
A magic sigil represents a wish. To create one:
1. Write the wish in uppercase.
2. Remove all vowels (A, E, I, O, U).
3. Remove all duplicate letters, **keeping the last occurrence**.
4. Remove spaces.

**Examples:**
- `"i am healthy"` → `"MLTHY"`
- `"I FOUND MY SOULMATE"` → `"FNDYSLMT"`
- `"I have a job I enjoy and it pays well"` → `"HVBJNDTPYSWL"`
