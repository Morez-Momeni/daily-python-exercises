# Problem 30: Find All Positions of a Character in a String

## Problem
Write a program that finds and prints all indices (positions) where a specific character (e.g., `'.'`) appears in a given string.

**Example:** 
For the string `"a.sd.zs.d.sd"`, the positions of dots are: `1, 4, 8, 10`.

---

## My Solution

I used the `str.find()` method inside a loop to locate every occurrence of the character `'.'`
