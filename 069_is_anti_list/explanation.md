# Problem 69: Anti-List Checker

## Problem
Write a function that receives two lists and checks whether they are **exactly opposite**. Two lists are considered opposite if:
- Both lists consist of only two different elements.
- The positions of these elements are exactly reversed: wherever the first list has element `a`, the second list has element `b`, and vice versa.

> **Note:** The problem guarantees that the input lists already satisfy the "two different elements" condition, so the function does not need to verify this.
