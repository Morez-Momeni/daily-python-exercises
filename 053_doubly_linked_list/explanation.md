# Problem 53: Doubly Linked List Implementation

## Problem
Implement a **doubly linked list** where each node has both a `next` and a `prev` pointer. The list should support the following operations:

- `add(new_node)` – append a node to the end.
- `return_as_list()` – return all elements as a Python list.
- `delete(val)` – remove the first node with the given value.
- `display()` – print elements forward.
- `display_reverse()` – print elements backward.
