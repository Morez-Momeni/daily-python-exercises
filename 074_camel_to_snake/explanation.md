# Problem 74: Camel Case to Snake Case Converter

## Problem
Write a function that receives a string in **camelCase** (or PascalCase) format and converts it to **snake_case**.

**Examples:**
- `"camelCase"` → `"camel_case"`
- `"CamelCase"` → `"camel_case"`
- `"myCamelCase"` → `"my_camel_case"`
- `"camel"` → `"camel"`
- `"ABC"` → `"a_b_c"
