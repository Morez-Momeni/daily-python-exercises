 Problem 76: Fibonacci with Memoization (Class-Based)

## Problem
Compute the n-th Fibonacci number using recursion. To make it efficient for larger inputs, use **memoization** — store previously computed results so each Fibonacci number is calculated only once.

The sequence is defined as:
- `F(1) = 1`
- `F(2) = 1`
- `F(n) = F(n-1) + F(n-2)` for `n > 2`

**Example:** `F(40) = 102334155`
