# Problem 77: ZIP Password Cracker (Dictionary Attack)

## Problem
Write a class `Cracker` that attempts to open an AES-encrypted ZIP file using a wordlist of candidate passwords. It should log incorrect passwords and return `True` when the correct password is found.

> ⚠️ **Educational purpose only.** This exercise is about file I/O, logging, and exception handling. Only use it on files you own or have explicit permission to access.
