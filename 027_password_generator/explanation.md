# Problem 27: Password Generator

## Problem
Write a function that generates a random password of a given length using a combination of:
- Uppercase letters (A–Z)
- Lowercase letters (a–z)
- Digits (0–9)
- Special characters (`~!@#$%^&*()_-+=><`)

The password should be generated securely and be suitable for use in applications requiring strong passwords.
