#Problem 47: Simple Music Player with Pygame

## Problem
Write a simple music player that loads an MP3 file and plays it using `pygame.mixer`. The program should wait for the user to press Enter before stopping.

## My Solution

I used `pygame.mixer` to:
1. Initialise the mixer.
2. Load the MP3 file.
3. Start playback.
4. Wait for user input (Enter) to exit.
